# DSH 自建插件市场页面设计方案 (dsh.127.dev)

## 1. 目标与定位

为 `dsh-plugins-index` 仓库提供一个现代、轻量、高质感的 Web 页面，托管在 `https://dsh.127.dev/`。

页面承担两项核心职责：
1. **插件源分发**：帮助 DSH 用户快速复制索引 URL（`https://dsh.127.dev/index.json`）并完成客户端配置。
2. **插件作品陈列**：清晰展示 polunzh 开发的 DSH 插件（如 `@polunzh/dsh-task-notifier`），呈现特性、版本、标签与源码链接。

## 3. 视觉与交互规范

1. **设计语言**：
   - 延续 DSH 与 macOS 现代桌面工具风格：低饱和度、清晰层级、精致微边框与微妙阴影。
   - 字体：系统无衬线字体栈（`system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`）。
   - 颜色规范：
     - 浅色模式：暖白底色（`#F9FAFB`）、卡片纯白（`#FFFFFF`）、边框（`#E5E7EB`）、主文本（`#111827`）、主强调色（`#2563EB` 蓝）。
     - 深色模式：深炭黑底色（`#0D1117`）、卡片暗灰（`#161B22`）、边框（`#30363D`）、主文本（`#F0F6FC`）、主强调色（`#388BFD` 蓝）。

2. **交互细节**：
   - **一键复制**：点击 URL 框或复制按钮，按钮状态变为绿勾「已复制」，提供明确微触觉反馈。
   - **双语切换**：中英按钮无缝切换文本，无页面跳转，默认跟随 `navigator.language`，并持久化到 `localStorage`。
   - **主题切换**：支持深色、浅色及跟随系统偏好，持久化到 `localStorage`。
   - **响应式支持**：完美适配桌面端大屏、平板及手机端（320px~1440px+）。

## 4. 技术实现方案

1. **产物与渲染机制**：
   - 采用**静态单文件构建**：`scripts/build-page.mjs` 读取 `index.json` 与 `site.json`，编译出单一、自包含、零外部请求的 `dist/index.html`（CSS、JS、图标全内联）。
   - 好处：无需外部 CDN，无额外网络往返，首屏毫秒级加载，完全免疫外部资源失效。

2. **Cloudflare Worker 路由分发**：
   - 修改 `worker/index.js`：
     - 请求 `/index.json`：维持现有行为，返回最新 JSON 数据（保持 5 分钟边缘缓存）。
     - 请求 `/` 或 `/index.html`：返回预生成的 HTML 页面内容（设置 `text/html; charset=utf-8` 与适度缓存）。
     - 其他路径：返回 404。

3. **数据一致性保证**：
   - 插件版本、描述与时间戳全部源自 `index.json`（其数据又来自 `plugins.json` + npm registry）。
   - `npm run build` 串联 `build-index.mjs` 与 `build-page.mjs`；`npm run check` 在离线状态下同时校验索引与页面产物是否过期。

## 5. 落地结果

1. **部署形式**：单文件静态页 + Worker 直出（`/` 与 `/index.html`），与 `/index.json` 同源同域，零新增依赖，不需要额外的 Pages 项目。
2. **文案与链接**：页面自身的文案放在 `site.json`；插件内容全部来自 `index.json`，新增插件无需改页面代码。
3. **多插件承载**：条目按数据自动平铺；出现第二个分类后自动显示分类筛选条。
4. **预览参数**：`?lang=en|zh`、`?theme=light|dark`，用于截图与分享指定语言的链接。
5. **数据同步**：页面加载时会再读一次 `/index.json`，索引刷新后页面自动跟上，不需要重建；构建期渲染的条目作为首屏与无 JS 兜底。
6. **文案取向**：面向使用插件的 DSH 用户，只讲「怎么用、能得到什么」；构建脚本、JSON 编辑、边缘缓存这类实现细节不进页面。
