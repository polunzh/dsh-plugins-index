# DSH 插件市场详情页与 Favicon 设计方案

## 1. 目标与范围

1. **插件详情页**：让每个收录的插件（如 `@polunzh/dsh-task-notifier`、`@polunzh/dsh-doc`）拥有专属的展示页面，包含下载数、真实 UI 截图画廊、完整功能特性与多途径安装指南。
2. **网站 Favicon**：为 `dsh.127.dev` 提供专属站点图标，支持深浅色自适应。

---

## 2. 详情页架构与交互形式

### 路由与导航（推荐：基于 Hash 的单页内嵌路由）
- **URL 规范**：
  - 首页列表：`https://dsh.127.dev/`
  - 插件详情：`https://dsh.127.dev/#/plugin/@polunzh/dsh-task-notifier`（支持短别名 `#/plugin/dsh-task-notifier`）
- **优势**：
  - 支持直接分享独立链接、浏览器原生前进/后退、页面刷新不丢失状态。
  - Cloudflare Worker 现有静态分发机制完全兼容，不需要复杂的后端路由规则。
  - 首屏秒开，切换无白屏等待。

## 4. 关键技术实现

### 1. 下载数（npm downloads）
- 客户端在打开详情页时，异步请求 npm 官方公共 API：
  `https://api.npmjs.org/downloads/point/last-week/@polunzh/dsh-task-notifier`
- 支持 CORS（官方已开启 `access-control-allow-origin: *`），客户端直连无需代理。
- 获取成功展示 `1.2k / 周`（或总计/近月）；若包刚发布未有统计数据，平滑降级不阻塞。

### 2. 截图资源管理
- 将截图优化为 WebP 格式存放在 `shots/<plugin-slug>/` 目录（例如 `shots/dsh-task-notifier/panel-light.webp`），每张压缩后仅 20~40 KB。
- 静态构建时直接内联或部署分发，保证加载速度。

### 3. Favicon 设计
- 设计专属矢量 SVG Favicon：
  - 采用 DSH 现代科技调性与插件接入几何符号。
  - 内置 CSS `@media (prefers-color-scheme: dark)`，深色模式自动适配高亮反色。
  - 在 HTML `<head>` 中以内联 SVG data URI 引入，零网络请求、零缓存失效问题。

## 5. 落地结果

1. **路由**：单页 Hash 路由 `#/plugin/<slug>`，列表与详情共用一个 HTML，Worker 无需新增页面路由；直接分享详情链接、浏览器前进/后退都可用。
2. **数据**：插件内容来自 `index.json`；截图、特性、许可来自 `plugins.json` 的 `detail` 块；周下载量构建时取 npm 统计接口并写入页面，打开详情时再通过 Worker 的 `/api/downloads` 刷新一次（取不到就不显示这一项）。
3. **截图**：`assets/shots/<slug>/*.webp`，宽约 1400 px、单张 20~45 KB，由 Worker 以 7 天边缘缓存分发。
4. **Favicon**：`assets/favicon.svg`（2×2 模块网格，最后一格用强调色）+ `favicon.ico` / `apple-touch-icon.png` 兜底，Worker 同时响应三个路径。
5. **安装说明**：三种途径（索引安装、按包名添加、CLI `dsh plugin --profile … add`），命令与包名都带一键复制。
